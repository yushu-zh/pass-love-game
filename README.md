# Pass Love Game

[网站](https://pass-love-game.netlify.app)

当天南海北的人因为同一份喜爱相聚在同一个场地，ta们会有什么共同的声音？一台设备、一群路人：一人写一个问题交给下一个人回答，回答者再写下新问题传给再下一个人……如此接力，直到最后一位收尾，整条问答链可以导出成一份可永久保存、可分享的美观记录。

本项目用于提供给活动组织者，使其便捷收集和管理数据。全程在浏览器里运行，数据只存在你自己的设备上。不需要注册、不强制联网、不上传任何内容。

---

## 如何举办这场活动：从开始到导出

1. **第一人开局**　打开应用，填三样东西：你的昵称、你想抛给下一个人的问题、以及你期待的下一人特征（例如「戴眼镜的男生」）。点「确认」开局。
2. **接力回答**　把设备递给你描述的那个人。他/她会看到你留下的问题，写下自己的回答和昵称，再出一个新问题 + 下一人特征，点「确认」把接力棒交出去。如此一人传一人。
   - 中途可点「返回」回到上一步修改。
   - 想结束就打开侧边「工具箱」，点「结束本轮」——此时只需回答和填昵称，不再出题。
3. **最后一位收尾**　作为最后一人确认提交后，这一轮就完成了。
4. **导出结果**　在工具箱或完成页可导出两种结果：
   - **导出 HTML**：得到一份独立的html网页，双击即可在任意浏览器打开。
   - **导出 JSON**：一份结构化备份文件，便于留档，以及交给ai分析处理。
5. **开启新一轮**　完成后可开启新一轮；为防误删，会要求你勾选确认（上一轮记录会被清空，请先导出保存）。

## 功能亮点

- **防丢（自动保存 + 离线）**
  - 每写一个字都自动存到本机，刷新页面或误关浏览器后重开，都能从上次的地方继续。
  - 没填完的半句话也会作为草稿保留，不会因为切到下一个人而丢掉。
  - 关闭或刷新有内容的页面时，浏览器会弹窗提醒，避免手滑丢失。
  - 万一本机存储不可用（如无痕模式、存储空间已满），页面顶部会跳出醒目提示，并直接给你一个「导出 JSON」按钮，先把内容抢救出来。
- **添加到主屏幕（当 App 用）**
  - 在手机或电脑浏览器里「添加到主屏幕 / 安装」后，它会像原生 App 一样全屏独立运行、有独立图标，离线也能用。
- **导出与分享**　HTML 日记可双击直接打开、可分享；JSON 用于备份。
- **字段限长 & 必填校验**　回答、昵称、问题、特征都有字数上限，必填项留空会提示，保证内容简洁完整。

| `public/icon.svg` 等 | 应用图标 |
